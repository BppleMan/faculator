# Faculator Web Agent Instructions

- Use `$build-faculator-web` for every task that creates, edits, refactors, reviews, or tests this Angular application.
- Use `$angular-developer` as the upstream Angular framework reference.
- Resolve conflicts in this order: explicit user instruction, `$build-faculator-web`, `$angular-developer`, then generic Angular defaults.
- Generate Angular artifacts with the workspace-local Angular CLI before editing them.
- Keep UI-system and visual-language decisions out of scope until the dedicated UI Skill is available or the user explicitly requests them.
