# 产线配平、唯一解与截流建模原则

## 本文目的

本文用于固定 Faculator 在“过程执行率、物料守恒、唯一解、剩余、截流、LP/MILP”上的建模口径。

Faculator 的核心不是替玩家优化蓝图布局，而是把固定产线计划下的稳定流量关系算清楚：

```text
先定义过程执行率
再建立物料守恒
再判断是否短缺、剩余或无解
最后才换算机器数量
```

## 核心经验

在 Factorio 中，很多玩家直觉上会认为：

```text
要么配不平
要么有唯一配平
```

这个直觉不是错的，但它成立有前提。

真正的原因不是 LP 天然只有唯一解，而是玩家通常已经固定了：

```text
配方路线
副产物去向
中间物是否允许剩余
目标产物速率
是否允许替代路线
```

当这些都固定后，问题就不再是“优化”，而是一个确定的物料守恒方程组。

## 唯一解成立的条件

如果产线模型满足：

```text
每种物料的生产来源已确定
每种副产物的消纳方式已确定
关键中间物不允许短缺
关键中间物不允许无限剩余
目标速率已指定
不存在可替代路线或未约束循环
```

那么模型可以写成：

```text
物料变化矩阵 × 过程执行率 = 目标向量
```

也就是：

```text
Sx = d
```

如果这个方程组满秩，且解出来的所有过程执行率都非负，那么配平就是唯一的。

这里的“唯一”指的是连续稳态流量意义上的唯一，不是机器整数数量意义上的唯一。

## 无解的含义

无解不一定是“代数上完全无解”。在游戏语义里，更常见的是：

```text
代数上有解
但某些过程执行率为负数
```

负数次执行配方在游戏中没有意义，所以这就是不可执行的配平。

因此游戏里的无解可以理解为：

```text
目标需求不落在当前配方网络的非负流量空间里
```

## 原油全裂化示例

以标准原油处理为例，设：

```text
a = 高级原油加工次数
b = 重油裂化次数
c = 轻油裂化次数
```

配方净变化：

```text
高级原油加工：
+25 重油
+45 轻油
+55 石油气

重油裂化：
-40 重油
+30 轻油

轻油裂化：
-30 轻油
+20 石油气
```

如果全裂化，只要求最终产出石油气，并要求重油和轻油没有剩余，那么：

```text
25a - 40b = 0
45a + 30b - 30c = 0
55a + 20c = P
```

这时每个变量都会被锁死，所以比例唯一。

## 截流的含义

截流不是特殊机制，而是把某种中间物提升为外部目标。

原本：

```text
重油剩余 = 0
轻油剩余 = 0
石油气 = P
```

加入截流后：

```text
重油截流 = H
轻油截流 = L
石油气 = P
```

方程变成：

```text
25a - 40b = H
45a + 30b - 30c = L
55a + 20c = P
```

如果解出来：

```text
a >= 0
b >= 0
c >= 0
```

则这个截流比例可行，而且通常唯一。

如果某个变量小于 0，则说明这个截流目标组合不可执行。

## 精确目标与下限目标

精确目标：

```text
石油气 = P
重油 = H
轻油 = L
```

特点：

```text
更容易无解
一旦有解，更容易唯一
```

下限目标：

```text
石油气 >= P
重油 >= H
轻油 >= L
```

特点：

```text
更容易有解
也更容易多解
```

因为允许多产、剩余或少裂化，系统会出现自由度。

因此在 Faculator 中，必须区分：

```text
目标必须精确满足
目标只需要至少满足
中间物必须清零
中间物允许剩余
副产物必须消纳
副产物允许作为输出保留
```

这些不是 UI 文案差异，而是决定方程是否唯一、是否多解、是否无解的建模条件。

## LP 与 MILP 的关系

Faculator 的核心未知数应首先是：

```text
过程执行率
```

而不是机器数。

LP 负责求：

```text
每个配方过程每分钟执行多少次
```

机器数是后续换算：

```text
理论机器数 = 过程执行率 / 单机执行率
实际机器数 = 向上取整
```

如果连续流量方程本身只有唯一解，那么 LP 和 MILP 在过程执行率上不会产生不同路线。

如果连续流量本身存在多解，MILP 才可能因为整数机器数量约束而选择另一条路线。

这意味着 Faculator 的基础层应优先保证：

```text
连续稳态流量正确
物料守恒正确
短缺和剩余解释正确
机器数量作为容量换算结果正确
```

整数机器全局最少属于更高阶的蓝图 sizing 问题，不应混入第一层物料守恒模型。

## 对红瓶基准表的影响

红瓶品质矩阵表中，如果只写：

```text
红瓶@5 >= 60/min
```

并允许其他物料剩余，那么这个问题通常是多解。

因此工作簿中的“可行解”只能解释为：

```text
满足目标且不短缺下游进料的一组稳定流量方案
```

不能解释为：

```text
唯一配平
最优蓝图
最少机器
最少资源
```

如果希望红瓶基准也呈现唯一解，需要额外固定：

```text
哪些低星红瓶允许剩余
哪些低星红瓶必须回收
哪些中间物允许剩余
哪些中间物必须清零
是否允许高星中间物流出产线
是否允许多产红瓶@5
```

这些约束一旦固定，完整矩阵就可以从“寻找任一可行解”收束为“求一个确定配平”。

## 建模经验结论

Factorio 玩家说的“配平唯一”，本质上是：

```text
固定产线拓扑后，
物料守恒方程组存在唯一非负解。
```

玩家说的“配不平”，本质上是：

```text
目标向量不在当前配方网络可达的非负流量空间里。
```

Faculator 应该优先表达这套经验：

```text
先定义过程执行率
再建立物料守恒
再判断是否短缺、剩余或无解
最后才换算机器数量
```

这样既符合玩家经验，也符合 LP 建模。
