# 红瓶品质线性规划基准

## 本文目的

本文用红瓶产线作为基准算例，固定说明三件事：

1. 基础配方如何变成物料变化表。
2. 品质模块如何把一个配方列扩展成多品质系数列。
3. 回收机如何作为额外过程列并入同一套线性规划。

本文讨论的是建模，不是代码。表格中的每一列表示一个“过程每分钟执行次数”，每一行表示一个“物料@星级”的平衡关系。

## 基础资料

以下配方只描述游戏工艺本身，不写机器、插件、速度、槽位。

```text
1 铜板 + 1 齿轮 -> 5 秒 -> 1 红瓶

2 铁板 -> 0.5 秒 -> 1 齿轮

1 铜矿 -> 3.2 秒 -> 1 铜板

1 铁矿 -> 3.2 秒 -> 1 铁板

铜矿区 -> 1 秒 -> 1 铜矿

铁矿区 -> 1 秒 -> 1 铁矿
```

机器和插件只在“配置后的过程列”中出现，因为只有配置确定后，才能知道该过程的品质升星率。

本文后续品质算例采用以下配置：

```text
电力采矿机：3 个槽位，插满传说品质插件 3，升星率 18.6%
电炉：2 个槽位，插满传说品质插件 3，升星率 12.4%
组装机 3 型：4 个槽位，插满传说品质插件 3，升星率 24.8%
回收机：4 个槽位，插满传说品质插件 3，升星率 24.8%
```

其中传说品质插件 3 单个提供 6.2% 升星率。

## 目标一：红瓶@1，60/min

### 规划展开

```text
60 红瓶@1 /分钟 <- 60 铜板@1 /分钟 + 60 齿轮@1 /分钟

60 齿轮@1 /分钟 <- 120 铁板@1 /分钟

60 铜板@1 /分钟 <- 60 铜矿@1 /分钟

120 铁板@1 /分钟 <- 120 铁矿@1 /分钟
```

### 物料变化

```text
红瓶制作：
-60 铜板@1
-60 齿轮@1
+60 红瓶@1

齿轮制作：
-120 铁板@1
+60 齿轮@1

铜板冶炼：
-60 铜矿@1
+60 铜板@1

铁板冶炼：
-120 铁矿@1
+120 铁板@1

铜矿采集：
+60 铜矿@1

铁矿采集：
+120 铁矿@1
```

### 未知数

```text
采铜矿 = 铜矿采集过程执行次数/分钟
采铁矿 = 铁矿采集过程执行次数/分钟
冶铜板 = 铜板冶炼过程执行次数/分钟
冶铁板 = 铁板冶炼过程执行次数/分钟
造齿轮 = 齿轮制作过程执行次数/分钟
造红瓶 = 红瓶制作过程执行次数/分钟
```

### 行和列

行，也就是物料：

```text
[铜矿@1, 铁矿@1, 铜板@1, 铁板@1, 齿轮@1, 红瓶@1]
```

列，也就是过程：

```text
采铜矿
采铁矿
冶铜板
冶铁板
造齿轮
造红瓶
```

### 矩阵

```text
                 采铜矿  采铁矿  冶铜板  冶铁板  造齿轮  造红瓶
铜矿@1              1      0     -1      0      0      0
铁矿@1              0      1      0     -1      0      0
铜板@1              0      0      1      0      0     -1
铁板@1              0      0      0      1     -2      0
齿轮@1              0      0      0      0      1     -1
红瓶@1              0      0      0      0      0      1

右侧目标：
[0, 0, 0, 0, 0, 60]
```

### 解

```text
采铜矿 = 60 次/分钟
采铁矿 = 120 次/分钟
冶铜板 = 60 次/分钟
冶铁板 = 120 次/分钟
造齿轮 = 60 次/分钟
造红瓶 = 60 次/分钟
```

## 目标三：红瓶@5，60/min，回收低星红瓶

### 红瓶回收过程

当前数据中的红瓶回收配方是：

```text
1 红瓶 -> 25% 概率返还 1 红瓶
```

也就是说，红瓶回收不是返还铜板和齿轮，而是 75% 损耗、25% 返还红瓶本身。其他物品是否返还原材料，需要看各自的回收配方。

回收机插满 4 个传说品质插件 3 时，升星率为 24.8%。所以一次低星红瓶回收过程等价于：

```text
先消耗 1 个对应星级红瓶
再以 25% 期望数量产出红瓶
产出的红瓶按 24.8% 品质矩阵升星
```

### 回收子矩阵

只回收红瓶@1 到红瓶@4，红瓶@5 保留为目标产物。

```text

红瓶@2             0.0558    -0.812       0          0
红瓶@3             0.00558    0.0558    -0.812       0
红瓶@4             0.000558   0.00558    0.0558    -0.812
红瓶@5             0.000062   0.000620   0.006200   0.062
```

读法：


### 拼接规则

在“不回收”的大矩阵基础上追加 4 个过程列：

```text

回收红瓶@2
回收红瓶@3
回收红瓶@4
```

只有红瓶组的行发生变化：

```text
红瓶组 = 组装矩阵 × 造红瓶组 + 回收矩阵 × 回收红瓶组
```

目标仍然是：

```text

红瓶@1..红瓶@4 不再作为保留目标，而是允许被回收列消耗
```

## 结论

1. 品质模块不改变线性规划的阶数，只改变过程列中的产出系数。
2. 回收机不需要展开无限轮，只需要作为额外过程列并入稳态矩阵。
3. 行是 `物料@星级`，列是 `配置后的过程`。
4. 基础配方不包含机器；过程列包含机器与插件配置，因为这决定品质矩阵。
5. 计算器的价值，就是自动生成这些行、列、系数、目标和边界条件，减少人工拼矩阵的机械劳动。
