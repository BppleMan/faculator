# Faculator MVP 验收用例

## 本文目的

本文用于固定 Faculator MVP 的最小验收集。

这些验收用例不是演示数据，而是实现正确性的基准。后续实现只要触碰 planner、solver、UI render model、机器换算或调试面板，都应该能回到这些用例上检查。

MVP 最小验收集包括：

```text
白板红瓶@1 60/min
红瓶@5 60/min，不回收
红瓶@5 60/min，带回收
原油处理/裂解副产物配平
```

其中前三个已经有红瓶基准文档和 Excel 作为参考资产：

```text
knowledge-base/red-bottle-quality-lp-reference.md
knowledge-base/red-bottle-quality-lp-reference.xlsx
```

原油配平原则参考：

```text
knowledge-base/production-balancing-principles.md
```

## 验收用例一：白板红瓶@1 60/min

### 目的

该用例验证最基础的配方链展开、物料守恒、过程执行率和机器换算。

它不涉及：

```text
品质模块
回收
副产物
多目标
下沉
外部供入
外供输出
```

如果这个用例不能稳定通过，说明基础 planner 或矩阵生成还没有站稳。

### 输入目标

```text
红瓶@1 >= 60/min
```

### 展开范围

全部在同一个解算域中展开：

```text
红瓶@1 60/min
  铜板@1
    铜矿@1
  齿轮@1
    铁板@1
      铁矿@1
```

基础配方：

```text
1 铜板 + 1 齿轮 -> 5 秒 -> 1 红瓶
2 铁板 -> 0.5 秒 -> 1 齿轮
1 铜矿 -> 3.2 秒 -> 1 铜板
1 铁矿 -> 3.2 秒 -> 1 铁板
铜矿区 -> 1 秒 -> 1 铜矿
铁矿区 -> 1 秒 -> 1 铁矿
```

### 期望过程执行率

```text
采铜矿 = 60 次/分钟
采铁矿 = 120 次/分钟
冶铜板 = 60 次/分钟
冶铁板 = 120 次/分钟
造齿轮 = 60 次/分钟
造红瓶 = 60 次/分钟
```

### 期望物料平衡

```text
铜矿@1 不短缺
铁矿@1 不短缺
铜板@1 不短缺
铁板@1 不短缺
齿轮@1 不短缺
红瓶@1 >= 60/min
```

除目标红瓶外，中间物在理想配平中应接近 0 剩余。

### UI 验收

普通 UI 应展示：

```text
目标：红瓶@1 >= 60/min
配方展开树
每个过程执行次数/分钟
所有关键物料无短缺
机器换算表
```

调试面板应展示：

```text
6 个过程变量
6 个物料行
物料变化矩阵
目标约束
求解状态为可行
红瓶@1 平衡产出 >= 60/min
```

## 验收用例二：红瓶@5 60/min，不回收

### 目的

该用例验证品质模块如何把单一过程扩展为多品质产出分布，并验证 `物料@品质` 作为独立物料行的建模方式。

它不验证回收闭环。

### 输入目标

```text
红瓶@5 >= 60/min
```

### 展开范围

全部在同一个解算域中展开：

```text
红瓶@5 60/min
  铜板
    铜矿
  齿轮
    铁板
      铁矿
```

每种中间物按品质拆成：

```text
@1
@2
@3
@4
@5
```

### 品质配置

该验收用例使用红瓶基准文档中的配置：

```text
电力采矿机：插满传说品质插件 3
电炉：插满传说品质插件 3
组装机 3 型：插满传说品质插件 3
```

对应升星率见红瓶基准文档和 Excel。

### 低星红瓶处理

低星红瓶不回收。

因此：

```text
红瓶@1
红瓶@2
红瓶@3
红瓶@4
```

允许作为剩余输出保留。

### 期望结果

系统需要找到一组过程执行率，使：

```text
红瓶@5 >= 60/min
关键中间物不短缺
低星红瓶允许剩余
```

红瓶基准 Excel 中的“无回收”工作表提供了一组参考可行解。

### UI 验收

普通 UI 应展示：

```text
目标：红瓶@5 >= 60/min
低星红瓶剩余
过程执行率
机器换算
红瓶@5 目标满足
```

UI 不应把低星红瓶自动丢弃。

UI 不应把低星红瓶自动回收。

调试面板应展示：

```text
物料行按 物料@品质 展开
过程列按 配方@输入品质 展开
品质矩阵系数
红瓶@1..@4 剩余
红瓶@5 平衡产出 >= 60/min
```

## 验收用例三：红瓶@5 60/min，带回收

### 目的

该用例验证回收机作为线性模型中的额外过程列，而不是 UI 上展开无限轮循环。

它也验证：

```text
低星产物可以被治理
回收损耗可以进入系数
回收品质模块升星可以进入系数
闭环在稳定流量下可求解
```

### 输入目标

```text
红瓶@5 >= 60/min
```

### 展开范围

红瓶生产链与用例二相同。

额外加入低星红瓶回收过程：

```text
回收红瓶@1
回收红瓶@2
回收红瓶@3
回收红瓶@4
```

红瓶@5 是目标产物，不回收。

### 回收语义

回收不是无限展开的 UI 轮次。

它应作为稳定流量模型中的过程列：

```text
回收红瓶@k：
-1 红瓶@k
+回收产出分布
```

回收产出分布需要同时体现：

```text
回收损耗
品质模块升星概率
```

具体系数见红瓶基准文档和 Excel。

### 期望结果

系统需要找到一组过程执行率，使：

```text
红瓶@5 >= 60/min
红瓶@1..@4 被回收闭环消纳
关键中间物不短缺
```

红瓶基准 Excel 中的“带回收”工作表提供了一组参考可行解。

### UI 验收

普通 UI 应展示：

```text
目标：红瓶@5 >= 60/min
低星红瓶进入回收治理
回收过程执行率
红瓶@5 目标满足
机器换算中包含回收机
```

UI 不应展开为：

```text
第 1 轮回收
第 2 轮回收
第 3 轮回收
后续无限轮回收
```

调试面板应展示：

```text
回收红瓶@1..@4 过程列
红瓶@1..@4 的消纳平衡
红瓶@5 的最终贡献
回收机对应的系数
求解状态
```

## 验收用例四：原油处理/裂解副产物配平

### 目的

该用例验证 Faculator 的线性模型不是只为品质副产物服务，也可以处理游戏中天然存在的多产物配方。

原油类配方的特点是：

```text
一个过程天然产出多种物料
某些副产物可以继续裂解
目标可能只关心最终某种产物
中间副产物可以要求清零、截流或保留
```

这能验证通用物料守恒模型。

### 基础示例

以高级原油加工和裂解为例：

```text
高级原油加工：
+25 重油
+45 轻油
+55 石油气

重油裂解：
-40 重油
+30 轻油

轻油裂解：
-30 轻油
+20 石油气
```

设：

```text
a = 高级原油加工次数/分钟
b = 重油裂解次数/分钟
c = 轻油裂解次数/分钟
```

如果要求全裂化，只保留石油气，并要求重油、轻油无剩余，则：

```text
25a - 40b = 0
45a + 30b - 30c = 0
55a + 20c >= P
```

### 期望能力

系统需要支持：

```text
多产物过程列
副产物继续作为下游输入
中间物清零约束
目标产物下限约束
过程执行次数非负
```

### UI 验收

普通 UI 应展示：

```text
高级原油加工
重油裂解
轻油裂解
重油平衡
轻油平衡
石油气目标满足情况
```

如果用户设置截流，例如保留一部分重油或轻油，UI 应显示这些截流目标。

### 调试面板验收

调试面板应展示：

```text
原油过程变量 a/b/c
重油/轻油/石油气物料行
每个过程的净变化系数
重油和轻油是否清零或截流
石油气是否满足目标
```

## 最低通过标准

MVP 可以认为通过最小验收，当且仅当：

```text
四个验收用例都能生成可解释结果
没有关键物料短缺被隐藏
剩余和副产物可见
机器换算与过程执行率分层展示
调试面板能解释每个解算域
```

如果某个案例只在调试面板中正确、普通 UI 无法表达，则 UI 还不满足 MVP。

如果普通 UI 看起来正确，但调试面板无法解释矩阵和变量，则核心可验证性不足。
